# Сборка APK через GitHub (без Android Studio)

В проект добавлен workflow `.github/workflows/android.yml`. Он собирает отладочный APK на серверах GitHub Actions.

## Как получить APK

1. На компьютере откройте [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите **New repository**, задайте имя, например `ShoppingListKotlin`, выберите **Private** или **Public** и создайте репозиторий.
3. На странице репозитория выберите **Add file → Upload files**.
4. Распакуйте этот архив на компьютере. Откройте папку `ShoppingListKotlin` и перетащите в окно GitHub всё её содержимое, включая скрытую папку `.github`. Важно: файл workflow должен оказаться по адресу `.github/workflows/android.yml` в корне репозитория.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions**. Выберите запуск **Build Android APK** и дождитесь зелёной отметки успешного выполнения.
7. Откройте завершившийся запуск workflow. Внизу страницы в разделе **Artifacts** скачайте `shopping-list-debug-apk` и распакуйте ZIP. Внутри будет `app-debug.apk`.

При первой загрузке GitHub может попросить подтвердить разрешение на запуск Actions — подтвердите его.

## Важно про iPhone

Файл APK предназначен для Android и не устанавливается на iPhone. Получить APK — значит проверить, что проект успешно компилируется, но это само по себе не проверяет работу интерфейса и SQLite на реальном устройстве. Для полноценного теста нужен Android-телефон или Android-эмулятор. Веб-эмуляторы существуют, но могут иметь ограничения и не гарантируют полноценную проверку всех функций.
